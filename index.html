Workshop log folder

Ranked code

The latest ranked release of Genji Ball, with the top 10 of this server and region tagged with their place and rating, and everyone else in a rank tier with its name. Paste it into the Workshop's import. The tags are as new as the code: get a new one when the leaderboard changes.

Live lobby

While a ranked match is played in your newest Workshop log, the site lists your lobby in the region above with how many players are in it. It's taken off when the match ends, the log stops growing (the game closed) or you quit the tool.

Uploads

    Ranked matches are uploaded when they end, or when the log stops growing. A failed upload is retried automatically. Only matches played since you saved a token for this server are uploaded. Closing this window keeps the tool uploading from the tray; quit it there.

    Updates

    The tool looks for a new version when it starts and every few hours, and installs one only when you click "Install and restart". The window closes while it installs; uploads carry on once the new version has started.
