Workshop log folder

Ranked code

The latest ranked release of Genji Ball (or the one picked under Advanced), with the top 10 of this server and region tagged with their place and rating, and everyone else in a rank tier with its name. Paste it into the Workshop's import. The tags are as new as the code: get a new one when the leaderboard changes.

Tourneys

    The tourney lobbies an admin assigned you, with their start in your time. "Copy tourney code" works from about an hour before the start: it's the ranked code with the lobby's tourney rule turned on (its name, label and round limit), and the rank tags of the tourney's region. Play it with the Tournament preset. When the match ends, screenshot the final standings and upload it here: an admin checks it against the match.

    Screenshots folder

    Where the tool looks for your newest screenshot of the final standings. Overwatch saves screenshots to Documents\Overwatch\ScreenShots\Overwatch.

    Live lobby

    While a ranked match is played in your newest Workshop log, the site lists your lobby in the region above with how many players are in it. It's taken off when the match ends, the log stops growing (the game closed) or you quit the tool.

    Uploads

      Ranked matches are uploaded when they end, or when the log stops growing. A failed upload is retried automatically. Only matches played since you saved a token for this server are uploaded. Closing this window keeps the tool uploading from the tray; quit it there.

      Updates

      It installs one only when you click "Install and restart". The window closes while it installs; uploads carry on once the new version has started.

      Advanced

      Timing

      Leave a value empty for its default. The defaults suit most hosts.

      Ranked code release

      The release "Copy ranked code" builds on, by its tag (like ). Leave it empty for the latest ranked release, which suits every host unless an admin asks for another.

      Updates

      "Stable" gets each version once it's released to everyone. "Pre-release" gets test versions too, before they are: pick it only if an admin asks you to try one. With the automatic checks off, use "Check for updates" yourself now and then.

      Debug

      How much the tool writes to its log. "debug" adds every token check and each answer's status; turn it on while you look into a problem.
