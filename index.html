        Region

        The region you host in now. More

        Ranked keeps EU and NA apart: switch it before you host in the other one. Your matches upload as it, the live lobby is listed in it, and the ranked code gets its rank tags. Your home region is the one an admin set for you.

        Data center

        Where the ranked code puts your lobby, for each region. More

        The ranked code and tourney codes set the lobby's data center (Lobby → Data Center Preference) to the one picked for their region, so the server matches the region's players. Importing the code into a running lobby moves it to that data center: players reconnect, so do it before the match. "Best available" leaves it to the game, which picks the best ping for you.

        The overlay is a separate see-through window that Windows draws over Overwatch. It lets every click through, never takes the focus, and only reads your Workshop logs and the ranked site, like the rest of the tool. It doesn't inject into the game, read its memory or send it keys.
